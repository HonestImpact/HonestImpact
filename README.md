## Production systems

### [Something They Don't See](https://somethingtheydontsee.com/) — Competitive intelligence, automated
Multi-agent research platform producing deep market analysis and custom reporting
for paying clients. Agent graph over a scheduled ingestion pipeline, with
multi-provider LLM routing and fallback so a single vendor outage doesn't stop a run.
**Stack**: FastAPI • LangGraph + LangChain • PostgreSQL (asyncpg + Alembic) • MCP server • APScheduler • Anthropic / OpenAI / Gemini • Docker

### [TryIt-AI (Noah)](https://tryitai.koyeb.app/) — Trust-first AI for skeptics
Multi-agent orchestration with metacognitive self-evaluation. Dual retrieval —
full-text search and vector similarity in a single PostgreSQL database — so
answers are grounded and the reasoning is visible. Built for people who see
through the hype.
**Stack**: Next.js 15 • LangGraph • PostgreSQL + pgvector • Supabase • TypeScript
[Code and trust architecture →](https://github.com/HonestImpact/TryItAIagentic/tree/feat/agentic-refactor)

### [Versus Recon](https://versusrecon.com/) — Competitive intel for content
Five automated workflows ingest competitor channels daily, detect signals humans
miss, and deliver a tactical brief every Monday.
**Stack**: n8n orchestration • Supabase • YouTube Data API • React

## Tools

### [FlipItFile](https://flipitfile.com/) — On-device file conversion
Free converters that run entirely in the browser. No accounts, no uploads, no
watermarks — the file never leaves your machine. Heavy decoding runs off the main
thread in Web Workers.
**Stack**: Astro • Tailwind v4 • TypeScript • WebAssembly + Web Workers • ffmpeg.wasm • jSquash • pdf-lib / pdf.js • Canvas API

### [Sidekick Chats](https://sidekickchats.com/) — Persistent AI personas
Conversational personas that hold context across sessions instead of starting cold
every time.

Small, single-purpose tools for the moments management actually gets hard —
Decision Debt Identifier, Feedback Flinch Neutralizer, Meeting Filter, and four
more. Static front end over n8n webhooks.
